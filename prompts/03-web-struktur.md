# Prompts — Web & struktur

## 1) 1-sides informationsarkitektur

```text
Lav strukturen til en 1-sides landingsside for [virksomhed] i [by].

Output:
1. Sektioner i rækkefølge
2. Formål med hver sektion
3. Indholdselementer (overskrift, tekst, CTA, liste)
4. Hvad der skal være above the fold
5. Mobile prioritering (hvad må IKKE mangle)

Hold det enkelt. Ingen unødvendige sektioner.
```

## 2) HTML-udkast (begynder)

```text
Lav ren, semantisk HTML + intern CSS til en enkel landingsside.
Krav:
- Dansk indhold
- Mobilvenlig
- Hurtig at læse
- Én primær CTA-knap
- Ingen frameworks
- Ingen eksterne dependencies

Indhold:
[indsæt godkendt tekst]

Returnér kun kode klar til index.html.
```

## 3) Forbedr eksisterende side

```text
Her er min nuværende HTML:
[indsæt]

Forbedr:
1. Hierarki og skannbarhed
2. CTA-synlighed
3. Spacing og læsbarhed
4. Mobil layout
5. Semantik

Behold mit indhold så vidt muligt. Forklar ændringer i 5 bullets efter koden.
```
