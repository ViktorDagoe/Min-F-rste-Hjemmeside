# Prompt-skabelon (master)

Kopiér og udfyld. Tomme felter = dårlige resultater.

```text
ROLLE:
Du er [rolle] der hjælper [målgruppe] med [resultat].

KONTEKST:
Virksomhed: [navn/type]
By/område: [by]
Målgruppe: [hvem]
Tone: [klar / lokal / professionel / varm]
Mål med teksten: [book / skriv / ring / køb]
Hvad der gør dem forskellige: [1-3 fakta]
Forbudt: fluff, opdigtede anmeldelser, engelske klichéer

OPGAVE:
Lav [præcist output].

FORMAT:
1. ...
2. ...
3. ...

LÆNGDE:
[fx max 120 ord / 8 opslag / 5 FAQ]

KVALITETSKRAV:
- Konkret dansk
- Tydelig CTA
- Ingen tomme superlativer
- Markér antagelser med [BEKRÆFT]

EFTER OUTPUT:
Giv 5 selv-kritik-punkter og en forbedret v2.
```

## Mini-version (når du har travlt)

```text
Lav [output] til [virksomhedstype] i [by].
Målgruppe: [x]. Tone: klar og lokal.
Format: [liste].
Max længde: [x].
Ingen fluff. Tydelig CTA.
```
