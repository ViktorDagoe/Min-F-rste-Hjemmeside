# Case-note — Viktor Dagø landingsside

## Case: AI Kickstart for lokale virksomheder i Horsens

### Problem

Repoet var en lærings-hub. CVR-firmaet Viktor Dagø (Horsens) havde ingen hjemmeside. En travl ejer kunne ikke på 20 sekunder se, hvad der sælges, hvad det koster, og hvordan man booker.

Linear-projektet kunne ikke læses i denne kørsel (MCP kræver login i desktop). Spec er derfor taget fra `sales/service-tilbud.md`, `projects/projekt-01-lokal-landingsside/BRIEF.md` og offentlige CVR-data.

### Hvad jeg leverede

- 1-sides landingsside i `index.html`
- Godkendt copy i `landing/tekst.md`
- Intern workstation-hub flyttet til `workstation.html`

### Før → Efter

**Før:** “Velkommen til min første hjemmeside” / intern AI-workstation.  
**Efter:** Kickstart-side med hero, 3 fordele, 2 pakker + scope, 3 trin, 5 FAQ og kontakt med rigtig telefon, mail og CVR.

### QA (8-punkt)

- [x] Mål: book 15 min / ring / skriv
- [x] Målgruppe: lokale servicevirksomheder i Horsens
- [x] Fakta: priser fra service-tilbud; “samme dag” og pilot markeret [BEKRÆFT] i tekst.md
- [x] Tone: kort dansk, ingen fluff
- [x] Længde: kan skimmes
- [x] Struktur: sektioner + sticky CTA på mobil
- [x] Originalitet: ingen klichéer eller fake anmeldelser
- [x] Ansvar: Linear-antagelse og [BEKRÆFT]-felter noteret

### 20-sekunders test

Hvad: tekst og opslag til lokale virksomheder.  
Hvor: Horsens.  
Hvordan: mail eller telefon.

### Næste skridt

1. Åbn siden på telefonen
2. Bekræft priser og “tilbud samme dag”
3. Hvis Linear peger på et andet firma: send projekt-URL
