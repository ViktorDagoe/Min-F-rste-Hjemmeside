# Case-note — Projekt 1

## Case: VVS i Helsingør (demo: Nordkyst VVS)

### Problem

En boligejer med utæt hane eller stoppet afløb skal på 20 sekunder forstå: hvad firmaet laver, hvor de kører, og hvordan man booker. Mange lokale sider drukner i fluff og fake anmeldelser — så man ringer ikke.

### Hvad jeg leverede

- 1-sides landingsside (`index.html`) — mobilvenlig, ren HTML/CSS
- Godkendt copy (`tekst.md`)
- Hero, 3 fordele, 3 ydelser, 3-trins proces, 4 FAQ, kontakt
- Primær CTA: ring. Sekundær CTA: skriv
- Demo-banner, så fiktiv telefon/mail ikke kan forveksles med rigtig virksomhed

### Før → Efter

**Før:** Tom `tekst.md` / `case-note.md`. HTML-udkast uden godkendt copy, uden tillidslinje, uden tydelig “skriv”-CTA i hero, og med font-navn der ikke blev indlæst.

**Efter:** En fremmed kan skimmes på 20 sekunder: VVS i Helsingør, tre ydelser, ring eller skriv.

### Tid brugt

Én samlet leverance i workstation (copy + HTML + QA + case-note).

### Hvad “kunden” kan gøre nu

- Åbne siden på telefonen og ringe eller skrive
- Skifte demo-telefon, mail og CVR til rigtige data
- Bruge siden som porteføljebevis ved outreach (Kickstart + mini-landingsside)

### QA (prompts/05 + manual/06)

| Tjek | Resultat |
|---|---|
| Mål (ring/skriv) | Ja — to knapper i hero, kontakt og mobilbar |
| Målgruppe | Boligejere i Helsingør — ikke “virksomheder generelt” |
| Fakta | Telefon, mail, åbningstider og CVR er markeret som demo / skal bekræftes |
| Tone | Kort dansk. Ingen “skræddersyet”, “næste level”, “vi brænder for” |
| Længde | Kan skimmes på 20–40 sekunder |
| Struktur | Overskrifter + kort kort + FAQ |
| Originalitet | Ingen “i en verden hvor…” |
| Ansvar | Demo-banner + footer siger, hvad kunden selv skal udfylde |
| Fake anmeldelser | Ingen. Tillidslinje: du taler med den, der kommer |
| 20-sekunders test | Hvad: VVS. Hvor: Helsingør. Næste skridt: ring eller skriv |

**Kundetest:** En travl ejer forstår tilbuddet. Tillid er begrænset, fordi det er demo-tal — det er meningen. Nej-risiko: “samme dag” er et forsøg, ikke et løfte (skrevet ind i FAQ).

**Leverance-accept:** Godkendt som **portefølje-demo**. Ikke kunde-klar til rigtig VVS, før kontakt og CVR er rigtige.
