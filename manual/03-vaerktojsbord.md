# 03 — Dit værktøjsbord

## Princip

Få færre værktøjer. Bliv farlig med dem.

Du behøver **ikke** 15 AI-apps. Du behøver et fast setup.

## Minimum-setup (anbefalet)

### 1. Editor med AI: Cursor

Brug Cursor til:

- at skrive og rette filer
- at bygge små websider
- at holde projekter i mapper
- at genbruge prompts og regler

### 2. Chat-AI til research og tekst

Brug ChatGPT/Claude til:

- brainstorm
- omskrivning
- kunde-research
- mailudkast

### 3. Visning/levering

Vælg én:

- GitHub + GitHub Pages
- Netlify Drop (træk-og-slip HTML)
- Google Docs / PDF til tekstleverancer

### 4. Sporing

Brug `workstation/scoreboard.md` og `workstation/fejl-log.md`.

## Sådan arbejder du i denne repo

```
manual/        → lær
workstation/   → planlæg og spor
prompts/       → genbrug gode instruktioner
projects/      → byg bevis
sales/         → sælg
.cursor/rules/ → hold AI’en i din stil
```

## Arbejdsflow for en typisk opgave

1. Skriv opgaven i 3 linjer (mål, målgruppe, output)
2. Find/skriv en prompt
3. Generér udkast med AI
4. Ret selv (fakta, tone, CTA)
5. Kør kvalitetstjek
6. Gem version 1
7. Lever eller publicér

## Filnavne der redder dig

Brug klare navne:

- `v1-udkast.md`
- `v2-kunde-klar.md`
- `outreach-liste.csv` eller `.md`
- `tilbud-frisoer-aarhus.md`

Undgå: `nyt dokument (3).md`

## Git for begyndere (nok til at starte)

Du behøver ikke mestre Git. Lær kun:

```bash
git status
git add .
git commit -m "kort besked om hvad du lavede"
git push
```

Commit når du har noget der virker — ikke kun når alt er perfekt.

## Cursor-regler (hvorfor de findes)

Filerne i `.cursor/rules/` hjælper dig med at:

- få AI til at svare konkret
- undgå fluff
- holde dansk forretningssprog
- prioritere leverancer over teori

Åbn dem og tilpas med dit navn, niche og tone senere.

## Daglig værktøjsrutine (10 min)

1. Åbn workstation-skabelon
2. Åbn relevant projektmappe
3. Åbn 1 prompt-fil
4. Arbejd
5. Commit/gem
6. Opdater scoreboard

## Det du skal undgå

- Installere nye tools hver dag
- Skifte model midt i en opgave uden grund
- Bruge 40 min på at “finde den bedste prompt-pack” online
- Bygge systemer før du har leverancer
