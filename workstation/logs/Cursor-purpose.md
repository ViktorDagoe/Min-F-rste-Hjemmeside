## Hvad Cursor er til (formål)

Cursor er dit arbejdspult — ikke bare en chat.

Brug Cursor til at:

1. Skrive og rette filer i dit projekt
2. Bygge små websider og leverancer
3. Holde arbejde i mapper (ikke løse noter)
4. Genbruge prompts og Cursor-regler
5. Få AI til at arbejde *i* din kodebase, ikke udenfor den

## Hvad Cursor ikke er

- En erstatning for din egen kvalitetskontrol
- Et sted til endeløs brainstorm uden output
- Et nyt tool hver dag

## Dit faste setup i denne repo

| Mappe | Formål |
|---|---|
| `manual/` | Lær — dansk manual + 90-dages plan |
| `workstation/` | Planlæg og spor (daglig/ugentlig) |
| `prompts/` | Genbrugelige instruktioner |
| `projects/` | Byg bevis / portefølje |
| `sales/` | Tilbud + outreach |
| `.cursor/rules/` | Hold AI’en konkret, dansk, anti-fluff |

## Daglig rutine (10–45 min)

1. Åbn `workstation/daglig-skabelon.md` (eller dagens log)
2. Åbn én projektmappe
3. Åbn én prompt
4. Byg én synlig leverance
5. Gem / commit
6. Opdater `workstation/scoreboard.md`

## Logging (så du husker hvad der virker)

- Dagslog: `workstation/logs/YYYY-MM-DD.md`
- Fejl: `workstation/fejl-log.md`
- Score: `workstation/scoreboard.md`
- Denne note: `workstation/logs/Cursor-purpose.md`
