# Opfølgningssekvens (7–14 dage)

Brug denne sekvens for hvert lead.

| Dag | Handling | Formål |
|---|---|---|
| 0 | Outreach sendt | åbne dør |
| 3–4 | Opfølgning #1 | blød reminder |
| 7–10 | Opfølgning #2 | luk eller løft |
| +1 efter svar | Book call | diagnose |
| Samme dag som call | Tilbud | beslutning |
| +3 efter tilbud | Opfølg på tilbud | lukke loop |
| +7 efter tilbud | Sidste check | win/loss |

## Statuskoder

- `NY`
- `SVAR`
- `CALL`
- `TILBUD`
- `VUNDET`
- `TABT`
- `PAUSE`
