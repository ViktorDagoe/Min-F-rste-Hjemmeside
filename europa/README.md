# Europe Strategic Atlas

Talte lektioner i Europas strategiske geografi.

Formålet er ikke at huske landeprofiler. Formålet er at kunne lukke øjnene og se **flows**: varer, energi, strøm, data, mennesker, forstærkning, mad, råstoffer, indflydelse — og de steder, hvor flere flows mødes.

## Sådan lytter du

1. Åbn episoden i `01-geografi/`.
2. Læs den højt, eller kør den gennem TTS.
3. Hold øjnene væk fra kort, hvis du kan. Rumligt sprog er meningen.
4. Kildenoterne er **ikke** til oplæsning. De er til at tjekke tal.

## Regel

Grænser fortæller, hvem der styrer territoriet.  
Netværk fortæller, hvordan territoriet faktisk fungerer.  
Geografi fortæller, hvorfor mange af netværkene ligger, hvor de gør.
