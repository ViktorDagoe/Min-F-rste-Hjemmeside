# AI Skill Workstation

Komplet lærings- og indtjeningsstation for begyndere, der vil bruge AI til **rigtige kundeopgaver** — ikke bare chat.

Denne mappe er dit arbejdsbord. Du læser manualen, træner i workstation, bygger projekter, genbruger prompts, og sælger en simpel service.

**Offentlig side:** `index.html` — Viktor Dagø, Kickstart for lokale virksomheder i Horsens.  
**Intern hub:** `workstation.html` — manual, prompts og projekter.

## Start her (5 minutter)

1. Åbn den offentlige side: `index.html`
2. Læs `manual/00-indholdsfortegnelse.md`
3. Læs `manual/01-kom-i-gang.md`
4. Kopiér dagens skabelon fra `workstation/daglig-skabelon.md`
5. Kør projekt 1 i `projects/projekt-01-lokal-landingsside/`

## Mappestruktur

| Mappe | Formål |
|---|---|
| `manual/` | Lang dansk læringsmanual + 90-dages roadmap |
| `workstation/` | Daglige og ugentlige skabeloner |
| `prompts/` | Genbrugelige prompts til rigtige opgaver |
| `projects/` | 5 begynderprojekter med konkrete briefs |
| `sales/` | Service-tilbud + outreach-beskeder |
| `.cursor/rules/` | Cursor-regler der holder dig på sporet |

## Målet på 90 dage

- Kunne levere AI-assisteret tekst, websider og små automatiseringer
- Have 5 porteføljeprojekter
- Have én klar service du kan sælge
- Have sendt outreach og booket samtaler
- Have fået din første betalte opgave (eller være tæt på)

## Regler (ingen fluff)

- Byg noget hver dag — også småt
- Gem alt arbejde i `projects/` eller din porteføljemappe
- Mål fremskridt i **leverancer**, ikke “timer brugt på at læse”
- Brug AI som medarbejder, ikke som underholdning
- Sælg én ting først: hurtige, konkrete resultater for lokale virksomheder
